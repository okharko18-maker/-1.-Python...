# Завдання 13. Один список замість трьох рядків (середнє)

Розгляньте два фрагменти.

```python
board = [[0] * 3] * 3
board[0][0] = 1
print(board)
```

```python
original = [[1, 2], [3, 4]]
copy_ = original.copy()
copy_[0].append(99)
print(original)
```

**Завдання.**
1. Автор першого фрагмента чекав `[[1, 0, 0], [0, 0, 0], [0, 0, 0]]`. Що виведе програма насправді? Поясніть причину через поняття посилання та псевдоніма і запропонуйте виправлення.
2. Що виведе другий фрагмент? Чому незмінений, на перший погляд, `original` змінився? Як зробити копію, незалежну від оригіналу?

**Обсяг:** до 10 речень і короткі виправлення коду.

---

Відповідь:

У першому фрагменті програма виведе `[[1, 0, 0], [1, 0, 0], [1, 0, 0]]`, тому що всі три рядки посилаються на один і той самий список. Такий зв'язок називається спільним посиланням, або псевдонімом. Коли змінюється перший елемент, зміни відображаються в усіх рядках. Щоб виправити це, потрібно створити окремий список для кожного рядка:

```python
board = [[0] * 3 for _ in range(3)]
board[0][0] = 1
print(board)
```

У другому фрагменті програма виведе `[[1, 2, 99], [3, 4]]`, оскільки метод `copy()` створює лише поверхневу копію, а вкладені списки залишаються спільними. Тому зміна вкладеного списку через `copy_` також змінює `original`. Для створення повністю незалежної копії потрібно використати `deepcopy()` з модуля `copy`:

```python
import copy
copy_ = copy.deepcopy(original)
```
