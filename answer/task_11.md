# Завдання 11. Ім'я і об'єкт: == проти is (легке)

У лекції 1 пояснено, що змінна в Python є іменем, прикріпленим до об'єкта, а не коробкою зі значенням.

**Завдання.** Своїми словами поясніть, чим відрізняються оператори `==` і `is`. У відповіді:
- скажіть, що саме перевіряє кожен із них;
- розгляньте `a = [1, 2]` і `b = [1, 2]`: що дадуть `a == b` та `a is b` і чому;
- назвіть випадок, у якому за стилем Python прийнято писати `is`, і поясніть, чому для порівняння чисел чи рядків `is` не годиться.

**Обсяг:** 5-8 речень.

---

Відповідь:
Оператор == перевіряє, чи однакові значення двох об'єктів, а оператор is перевіряє, чи це один і той самий об'єкт у пам'яті. Наприклад, якщо a = [1, 2] і b = [1, 2], то a == b поверне True, оскільки списки мають однакові елементи. Але a is b поверне False, тому що це два різні об'єкти, хоча їхній вміст однаковий. У Python оператор is прийнято використовувати для перевірки, чи змінна дорівнює None, наприклад x is None. Для порівняння чисел або рядків оператор is не підходить, оскільки він перевіряє не значення, а тотожність об'єктів. Тому для порівняння значень потрібно використовувати ==.
