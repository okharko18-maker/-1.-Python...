# Завдання 12. Блок else у циклі (легке)

Мова Python має конструкцію, якої немає в багатьох інших мовах: блок `else` після циклу `for` або `while`.

**Завдання.** Поясніть, коли цей блок виконується, а коли ні. Напишіть короткий приклад (4-6 рядків коду): пошук першого від'ємного числа у списку, де `else` повідомляє, що від'ємних чисел немає. Скажіть, яку допоміжну змінну такий запис дозволяє не заводити.

**Обсяг:** 4-6 речень і невеликий фрагмент коду.

---

Відповідь:


Блок `else` після циклу `for` або `while` виконується тоді, коли цикл завершився звичайним способом, без команди `break`. Якщо команда `break` перервала цикл, блок `else` не виконується. Наприклад, можна знайти перше від'ємне число у списку:

```python
numbers = [5, 8, -3, 4]
for number in numbers:
    if number < 0:
        print("Знайдено:", number)
        break
else:
    print("Від'ємних чисел немає")
```

Якщо від'ємного числа немає, програма виконає блок `else`. Такий запис дозволяє не створювати додаткову змінну-прапорець, яка повідомляла б, чи знайдено потрібне число.
