# Завдання 14. Лічильник, що не рахує (середнє)

Розгляньте код.

```python
total = 0

def add(x):
    total = total + x
    return total

def collect(item, bucket=[]):
    bucket.append(item)
    return bucket

print(add(5))
print(collect(1))
print(collect(2))
```

**Завдання.** Для кожної функції скажіть, що станеться під час виконання, і поясніть механізм (правило пошуку імен LEGB для першої функції; момент обчислення значення за замовчуванням для другої). Запропонуйте виправлені версії обох функцій.

**Обсяг:** до 10 речень і виправлений код.

---

Відповідь:

У функції `add()` виникне помилка `UnboundLocalError`, тому що Python вважає змінну `total` локальною, оскільки їй присвоюється значення всередині функції. За правилом LEGB Python шукає змінні спочатку локально, потім у зовнішніх областях, глобально та у вбудованих іменах. Щоб змінювати глобальну змінну, потрібно використати `global total`. У функції `collect()` список `bucket` створюється лише один раз під час визначення функції, тому наступні виклики продовжують додавати елементи до того самого списку. Через це результати будуть `[1]`, а потім `[1, 2]`. Щоб уникнути цієї проблеми, краще використовувати `None` як значення за замовчуванням і створювати новий список усередині функції.

Виправлений код:

```python
total = 0

def add(x):
    global total
    total += x
    return total

def collect(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

print(add(5))
print(collect(1))
print(collect(2))
```
